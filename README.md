# AI Metra Bot

A bilingual (FA/EN) intelligent quantity surveying bot with AI-powered image analysis.

## Features
- AI-based quantity surveying
- Image analysis for construction materials
- 3 free daily analyses
- Pro version (monthly subscription)
- ZarinPal payment (IRR)
- Wallet payment (USD)
- Referral system
- Channel membership verification
- Full admin panel

## Tech Stack
- Python
- Aiogram
- Flask (for backend API)
- Render (development hosting)
- VPS (optional for production)
